# Yuyin's Geo Journey

A personal webpage and interactive web map connecting my hometown, Beijing, with the University of Southern California (USC).

## About the Project

This project was created for Demo 1. It introduces my academic background and interests while demonstrating an interactive web map. Visitors can use the buttons to move between Beijing and USC.

## Features

- Personal introduction
- Interactive Leaflet web map
- Navigation between Beijing and USC
- Customized webpage design

## Technologies

- HTML
- CSS
- JavaScript
- Leaflet
- OpenStreetMap

## How to Run

Download the project and open `index.html` in a web browser.
